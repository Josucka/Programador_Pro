# Map-CSharp

With the help of Copilot, I developed this learning roadmap to strengthen my programming skills. If you're just starting out, I highly recommend creating a study plan like this. It has been incredibly helpful for my learning journey.

Ótima decisão! Se você já sabe usar o Visual Studio, o foco pode ser aprender lógica, C# e desenvolvimento de projetos reais. O segredo é estudar e programar ao mesmo tempo.

## Plano de Estudos em C# (6 meses)<br>
Fase 1: Fundamentos da Programação (Semanas 1 a 4)<br>
## Objetivos<br>
- Entender lógica de programação.<br>
- Aprender a sintaxe básica do C#.<br>
## Estudar<br>
- Variáveis e tipos de dados<br>
- Operadores matemáticos e lógicos<br>
- Entrada e saída de dados (Console.WriteLine, Console.ReadLine)<br>
- Estruturas condicionais (if, else, switch)<br>
- Estruturas de repetição (for, while, foreach)<br>
## Projetos<br>
- Calculadora simples<br>
- Conversor de moedas<br>
- Jogo de adivinhação de números<br>
- Sistema de notas escolares<br>
## Exercícios<br>
- Faça pelo menos 10 exercícios por tópico.<br>

Fase 2: Métodos e Programação Orientada a Objetos (Semanas 5 a 8)<br>
## Estudar<br>
- Métodos e parâmetros<br>
- Classes e objetos<br>
- Construtores<br>
- Encapsulamento<br>
- Herança<br>
- Polimorfismo<br>
- Abstração<br>
## Projetos<br>
- Sistema de cadastro de clientes<br>
- Cadastro de produtos<br>
- Controle de estoque simples<br>
- Sistema bancário com contas e transferências<br>
## Objetivo<br>
Começar a pensar como um desenvolvedor profissional.<br>

Fase 3: Coleções e Manipulação de Dados (Semanas 9 a 12)<br>
## Estudar<br>
- Arrays<br>
- List<br>
- Dictionary<br>
- LINQ básico<br>
- Tratamento de erros (try/catch)<br>
## Projetos<br>
- Agenda de contatos<br>
- Biblioteca de livros<br>
- Gerenciador de tarefas<br>
## Desafio<br>
- Criar um sistema que permita:<br>
- Adicionar<br>
- Editar<br>
- Excluir<br>
- Listar dados<br>

Fase 4: Banco de Dados (Semanas 13 a 16)<br>
## Estudar<br>
- SQL Básico<br>
- SQL Server Express<br>
- Entity Framework Core<br>
- CRUD<br>
## Projetos<br>
- Sistema de vendas<br>
- Cadastro de clientes com banco<br>
- Controle financeiro<br>
## Aprender<br>
- SELECT<br>
- INSERT<br>
- UPDATE<br>
- DELETE<br>
- JOIN<br>

Fase 5: Desenvolvimento Desktop (Semanas 17 a 20)<br>

## Aprenda:<br>

- Windows Forms (mais simples) ou
WPF (mais profissional)
## Projetos<br>
- Sistema de estoque<br>
- Sistema de caixa<br>
- Agenda visual<br>

## Objetivo<br>

- Criar interfaces gráficas.<br>

Fase 6: Desenvolvimento Web com ASP.NET Core (Semanas 21 a 24)<br>
## Estudar<br>
- HTTP<br>
- HTML<br>
- CSS<br>
- ASP.NET Core MVC<br>
- APIs REST<br>
## Projetos<br>
- Site de cadastro de clientes<br>
- Blog pessoal<br>
- API de produtos<br>
- Conceitos importantes<br>
- Controllers<br>
- Models<br>
- Views<br>
- CRUD Web<br>

# Projetos para Portfólio

Ao final dos estudos, tenha no GitHub:

 ✅ Calculadora
 ✅ Sistema Bancário
 ✅ Agenda de Contatos
 ✅ Controle de Estoque
 ✅ Sistema de Vendas com Banco de Dados

Ferramentas que você deve dominar
-- Visual Studio
-- Git
-- GitHub
-- SQL Server
-- Entity Framework Core
-- ASP.NET Core
-- Postman
-- Azure (básico)
-- Meta Final

Depois de 6 meses estudando de forma consistente (1 a 2 horas por dia), você deverá conseguir:

Criar aplicações em C# sozinho.
Trabalhar com banco de dados.
Desenvolver APIs.
Construir sistemas desktop e web.
Publicar projetos no GitHub para montar um portfólio profissional.

Minha sugestão é começar hoje mesmo pela Calculadora em Console, porque ela já ensina variáveis, operações matemáticas, condições e entrada de dados em um único projeto.
